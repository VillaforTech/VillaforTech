## Selected public work

- **[Fairness-Aware Candidate Pre-Screening](https://github.com/VillaforTech/Fairness-Aware-Candidate-Pre-Screening)** is an experimental responsible-ML pipeline built on the UCI Adult dataset. It separates threshold tuning from test evaluation and includes fairness metrics, governance checks, a command-line interface, an API surface, and automated tests.
- **[Bio-Inspired Optimization Benchmark](https://github.com/VillaforTech/Bio-Inspired-Optimization-Benchmark)** is a deterministic Python benchmark runner for genetic algorithms, particle swarm optimization, ant colony optimization, and grey wolf optimization across continuous functions, TSP, and scheduling tasks. Runs preserve seeds, configuration, convergence data, and result artifacts.
